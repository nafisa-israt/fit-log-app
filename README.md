# FITLOG

A modern and responsive workout library built with Next.js.

## 📌 About The Project

FitLog is a workout library where users can explore different workouts, view detailed workout information, save workouts for later, and add workouts to their personal plan.

The project features a dark, modern fitness-focused interface with a lime green accent color.

## ✨ Features

- Browse workout library
- Sort workouts by duration, calories, and rating
- View detailed workout information
- Add workouts to Today's Plan
- Save workouts for later
- Mark workouts as completed
- Remove workouts from the plan
- Responsive design for mobile, tablet, and desktop
- Loading state
- 404 workout-not-found page
- Toast notifications
- Data stored using localStorage

## 🛠️ Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- Lucide React
- REST API
- localStorage

## 📂 Main Pages

### Home

Displays the workout library with workout cards and sorting options.

### Workout Details

Shows detailed information about a selected workout, including:

- Muscle groups
- Equipment
- Duration
- Calories
- Sets and reps
- Rating
- Description
- Instructions

### My Plan

Allows users to manage their selected workouts and saved workouts.
